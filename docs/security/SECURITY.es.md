## Notificación de vulnerabilidades

No abra un issue público para reportar un problema de seguridad.

Utilice el reporte privado de vulnerabilidades de GitHub en su lugar:

➡ <https://github.com/leejongyoung/egovframe-chocolatey/security/advisories/new>

## Alcance

### In scope
- Definiciones del paquete (`egovframe.nuspec`), scripts de instalación (`tools/`), flujos de trabajo (`.github/workflows/`) y scripts auxiliares (`scripts/`).

### Out of scope
- El framework eGovFrame en sí → repórtelo a través del portal oficial (<https://www.egovframe.go.kr/>).
- Chocolatey en sí → <https://github.com/chocolatey/choco/security/policy>.
