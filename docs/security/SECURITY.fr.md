## Signaler une vulnérabilité

Veuillez ne pas ouvrir d'issue publique pour un problème de sécurité.

Utilisez plutôt le signalement privé de vulnérabilités de GitHub :

➡ <https://github.com/leejongyoung/egovframe-chocolatey/security/advisories/new>

## Périmètre

### In scope
- Définitions du package (`egovframe.nuspec`), scripts d'installation (`tools/`), workflows (`.github/workflows/`) et scripts utilitaires (`scripts/`).

### Out of scope
- Le framework eGovFrame lui-même → signalez-le via le portail officiel (<https://www.egovframe.go.kr/>).
- Chocolatey lui-même → <https://github.com/chocolatey/choco/security/policy>.
