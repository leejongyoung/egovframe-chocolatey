## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private vulnerability reporting instead:

➡ <https://github.com/leejongyoung/egovframe-chocolatey/security/advisories/new>

## Scope

### In scope
- Package definitions (`egovframe.nuspec`), installation scripts (`tools/`), workflows (`.github/workflows/`), and helper scripts (`scripts/`).

### Out of scope
- The eGovFrame framework itself → report through the official portal (<https://www.egovframe.go.kr/>).
- Chocolatey itself → <https://github.com/chocolatey/choco/security/policy>.
