## النطاق

### In scope
- تعريفات الحزمة (`egovframe.nuspec`)، نصوص التثبيت (`tools/`)، مسارات العمل (`.github/workflows/`)، ونصوص المساعدة (`scripts/`).

### Out of scope
- إطار عمل eGovFrame نفسه → أبلغ عبر البوابة الرسمية (<https://www.egovframe.go.kr/>).
- Chocolatey نفسه → <https://github.com/chocolatey/choco/security/policy>.
