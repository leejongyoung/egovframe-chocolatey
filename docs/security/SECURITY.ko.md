## 보안 범위

### In scope
- 패키지 정의(`egovframe.nuspec`), 설치 스크립트(`tools/`), 워크플로우(`.github/workflows/`), 보조 스크립트(`scripts/`).

### Out of scope
- eGovFrame 프레임워크 자체 → 공식 포털(<https://www.egovframe.go.kr/>)을 통해 신고해 주세요.
- Chocolatey 자체 → <https://github.com/chocolatey/choco/security/policy>.
