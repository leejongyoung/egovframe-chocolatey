## Phạm vi

### In scope
- Định nghĩa gói (`egovframe.nuspec`), script cài đặt (`tools/`), workflow (`.github/workflows/`) và script bổ trợ (`scripts/`).

### Out of scope
- Bản thân framework eGovFrame → báo cáo qua cổng thông tin chính thức (<https://www.egovframe.go.kr/>).
- Bản thân Chocolatey → <https://github.com/chocolatey/choco/security/policy>.
